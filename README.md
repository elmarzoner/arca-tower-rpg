# アルカの塔 〜百層の物語〜

塔を登る物語を描く、高精細2DファンタジーRPG。
世界は一本の巨大な塔「アルカ」だけ。100階の頂上「てんがいの間」を目指して登る物語です。

**グラフィック・音楽・シナリオ・キャラクター・モンスターはすべて本作のために制作したオリジナルです。Visual System IVではレトロ画質の再現をやめ、描き下ろし村マップ、環境アトラス、魔物アトラス、主要人物原画、戦闘背景へ全面更新しました。画面上のサイズ感とゲーム性は維持しています。**

## 遊び方

ブラウザだけで動きます。どちらかの方法で起動:

```bash
open index.html
```

またはローカルサーバーで:

```bash
python3 -m http.server 8642
```

→ http://localhost:8642 を開く

## ゲームシステム

- **100階の塔**: 10階ごとにボス、x1階(11F, 21F…)は宿場町(宿屋・道具屋・武具屋・NPC)。その他の階は階ごとに固定シードの自動生成ダンジョン。
- **モンスターを仲間に(レア)**: 戦闘勝利後、ごくまれに倒したモンスターが起き上がって仲間になる(DQ5方式)。出会えたら大切に——確率は序盤で1割前後、上層では3〜5%。戦闘中に「ほしにく」を使うと確率3倍。控えを含め最大12体。
- **パーティー**: 最大4人。主人公以外の3枠は人間・モンスターを自由に混成でき、フィールドでも全員が主人公の歩いた経路を追従します。同じ種類のモンスターは、戦闘メンバーと控えを合わせて1体まで仲間にできます。
- **スマートフォン**: 画面左側の好きな位置に触れると出現する追従式スティックと、決定・戻る/メニューボタンで操作できます。縦持ち・横持ちの両方に対応しています。
- **じゅもん**: ヒノン(火)・ビリム(雷)・ヒヤリ(氷)・ホロン(回復)・リバイム(蘇生)・トベール(行った宿場町へワープ)など全16種のオリジナル呪文。
- **転職**: 31Fバザーラの「みちびきのみこ」でソラ以外の人間メンバー(Lv12以上)が転職できる。せんし/ぶとうか/そうりょ/まほうつかい/とうぞく/しょうにん+隠し職けんじゃ(50Fの石碑後に解禁)。レベルは1に戻るが呪文は全て引き継ぎ、鍛えた能力の一部も「たくわえ」として残る。
- **セーブ**: メニュー「きろく」でどこでもセーブ(ブラウザのlocalStorage)。全滅すると最後に訪れた宿場町で復活(所持金半分)。

## ストーリー

> 世界は「ほしばみの霧」に呑まれ、人々は塔「アルカ」に逃げ込んだ。
> 千年後——誰も塔の外を知らない。
> 百年に一人、胸に塔の紋章が灯る者「のぼりて」だけが、頂を目指すことを許される。
> 100年前、一人の少女が登った。そして帰らなかった。

**三つの縦糸**が絡み合う物語:

1. **セツナの手記(収集要素・全10篇)** — 100年前ののぼりて少女セツナが塔に遺した手記。妹の病を治すため登った彼女の旅路が、あなたの旅と重なっていく。全て集めると最終決戦後に隠しシーンが追加され、エンディングに後日譚が加わる。
2. **守り手たちの物語** — 10階ごとのボスは単なる敵ではない。力なき者を通して死なせた後悔を持つ門番、欲に堕ちた元のぼりて、現実に耐えられず皆の悪夢を引き受けた元のぼりて、千年ねぎらわれず働き続けた機械——それぞれが「人の心の関門」。
3. **選定の真実** — なぜソラが選ばれたのか。50Fの石碑で明かされる「扉を閉ざしたのはアルカの意志ではなく命令」という事実、60Fの機械神が遺す「塔の寿命」の警告、90Fの影が語る出自の秘密が、100Fで一つに繋がる。

**エンディングは選択分岐**: 最終決戦後、「いま扉をひらくか」の問いにどう答えるかで結末が変わる(2種+手記コンプリートによる後日譚)。
