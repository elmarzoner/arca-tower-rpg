# アルカの塔 〜百層の物語〜

塔を登る物語を描く、高精細2DファンタジーRPG。
現在の公開版は第一部・1〜40階。夜の女王ノクターナが待つ40階を目指します。百層構想の41階以降は、第一部公開後のアップデートで制作します。

**グラフィック・音楽・シナリオ・キャラクター・モンスターはすべて本作のために制作したオリジナルです。現在版ではレトロ画質の再現をやめ、地域別の町・環境・魔物・戦闘背景、主要人物原画、方向別の町人素材へ全面更新しました。画面上のサイズ感とゲーム性は維持しています。**

## 遊び方

ブラウザだけで動きます。どちらかの方法で起動:

```bash
open index.html
```

またはローカルサーバーで:

```bash
python3 -m http.server 8642
```

→ http://localhost:8642 を開く

## ゲームシステム

- **第一部は1〜40階**: 10階ごとにボス。40階ボス撃破で第一部クリアとなり、自動保存後も下層の探索や仲間集めを続けられます。
- **モンスターを仲間に**: 戦闘勝利後、倒したモンスターが起き上がることがあります。最初の仲間は対象戦闘3回以内、その後も6回以内に必ず候補が現れ、戦闘中の「ほしにく」で基本確率が3倍になります。同じ種類は1体まで。パーティーと控えを合わせて最大20人です。
- **パーティー**: 最大4人。主人公以外の3枠は人間・モンスターを自由に混成でき、フィールドでも全員が主人公の歩いた経路を追従します。同じ種類のモンスターは、戦闘メンバーと控えを合わせて1体まで仲間にできます。
- **スマートフォン**: 画面左側の好きな位置に触れると出現する追従式スティックと、決定・戻る/メニューボタンで操作できます。縦持ち・横持ちの両方に対応しています。
- **じゅもん**: ヒノン(火)・ビリム(雷)・ヒヤリ(氷)・ホロン(回復)・リバイム(蘇生)・トベール(行った宿場町へワープ)など全16種のオリジナル呪文。
- **転職**: 31Fバザーラの「みちびきのみこ」で、ソラ以外の人間メンバー(Lv12以上)が、せんし/ぶとうか/そうりょ/まほうつかい/とうぞく/しょうにんへ転職できます。レベルは元の70%(最低Lv5)になり、呪文と鍛えた能力の一部を引き継ぎます。
- **セーブ**: メニュー「きろく」でどこでもセーブ(ブラウザのlocalStorage)。全滅すると最後に訪れた宿場町で復活(所持金半分)。

## ストーリー

> 世界は「ほしばみの霧」に呑まれ、人々は塔「アルカ」に逃げ込んだ。
> 千年後——誰も塔の外を知らない。
> 百年に一人、胸に塔の紋章が灯る者「のぼりて」だけが、頂を目指すことを許される。
> 100年前、一人の少女が登った。そして帰らなかった。

**三つの縦糸**が絡み合う物語:

1. **セツナの手記** — 100年前ののぼりて少女セツナが塔に遺した手記。第一部では3F・15F・25F・35Fの4篇を読め、妹の病を治すため登った彼女の旅路が、あなたの旅と重なっていく。
2. **守り手たちの物語** — 10階ごとのボスは単なる敵ではない。力なき者を通して死なせた後悔を持つ門番、欲に堕ちた元のぼりて、現実に耐えられず皆の悪夢を引き受けた元のぼりて、千年ねぎらわれず働き続けた機械——それぞれが「人の心の関門」。
3. **選定の真実** — なぜソラが選ばれたのか。第一部では四人の守り手と「あけぼのの門」を通じて最初の答えに触れ、残る謎は次章へ続きます。

40Fのノクターナ撃破で第一部の章末へ到達します。クリア後も同じセーブで1〜40階を探索でき、仲間集めや手記の回収を続けられます。
