# Visual System VII — motion & interface

2026-09-06。第一部1〜40Fの内容・戦闘ルール・既存セーブ形式を維持した表示と操作の改訂。

## 移動

- 主人公は4.4 tiles/s。空間補間は線形、フレーム内の残り時間を次のタイルへ渡す。タイルごとの再加速と停止をなくす。
- onStepは完了タイルにつき1回。遭遇・階段・落とし穴・画面遷移では残り時間を破棄する。
- 移動中の会話/メニュー入力は次のマス中心まで予約。障害物・イベント・入力解放時もグリッド位置を保持する。
- 各隊列メンバーは直交経路を追い、実移動距離から個別の歩行位相を求める。曲がり角を斜めに省略しない。
- カメラは指数補間。ワープ/フロア遷移は位置をリセットする。
- 人物の既存6コマ歩行、町人の既存4方向立ち姿を使用。セルごとの透明余白を初回だけ解析し、接地点の誤差を最大±3 logical px補正する。町人に新しい歩行コマを追加したわけではない。

## 画面と操作

- 濃紺・真鍮・控えめなシアンを共通化。選択ハイライトは滑らかに移動し、人物カードには高精細素材を優先する。
- 道具・装備・呪文・仲間の長い一覧は選択位置を追う表示範囲に限定し、詳細と装備差分を別領域へ表示する。
- 会話は描画フォントの実幅で折り返し、最大3行ごとにページ化。全文表示と次ページを分け、完了コールバックは最後に1回だけ実行する。
- ショップは購入確認を独立したモーダルにする。背面のタップ領域を消し、確認前に所持金を変更しない。
- 項目は1回目で選択、同じ項目をもう一度押すと決定。すでに選択されている項目はそのタップで決定する。画面遷移中と古い画面のタップ領域は無効化する。
- 方向キー長押しは360ms後から120ms間隔。メニューを切り替えたら方向入力の残りを破棄する。マウスホイール/上下スライドにも対応する。
- スマホのフローティングスティックは指の移動に中心も追従し、対角線付近の細かな方向切替を抑える。メニューでは移動領域を透過させ、一覧を直接タップできる。
- PC、スマホ縦/横の画面枠を分離。右上の「?」に操作ガイドと演出軽減設定。ガイド表示中・非表示タブではゲーム更新を停止する。

## 戦闘

- 地上敵は接地した呼吸/攻撃/被弾表現、飛行系は浮遊表現。攻撃前進、反動、撃破/逃走フェードを追加する。
- 残敵の再配置とHPバーを補間。撃破フェード中は元の隊列位置を保持する。
- 被弾フラッシュはスプライト形状に沿わせる。コマンド・呪文/道具・対象選択は画面下部へまとめる。
- パーティー4枠のHP/MPと状態、選択中/行動中/対象の区別を表示。戦闘の選択ハイライトも共通UIを使用する。
- 演出軽減は戦闘の揺れ/補間と人物の追加上下動に適用し、歩行速度や戦闘ルールは変えない。

## 検証

`node --test tests/*.test.cjs` で再実行可能。9テスト成功。

- 移動: 60/120fps・変動dt一致、衝突、残差、中断、メニュー予約、直交隊列、NPC、補正キャッシュ
- 戦闘: 隊列/HP補間、撃破重複防止、演出受け渡し、長い一覧、タップ/各対象、4人表示
- UI: 長い一覧、購入確認、会話改行/ページ/コールバック、タイトル/選択肢のタップ
- 操作: キーリピート、短いタップ、画面間入力分離、ガイド、停止、座標変換、スワイプ、表示サイズ
