# Visual System IV

## 変更理由

Visual System IIIは素材解像度を上げたものの、造形そのものが単純なCanvas図形と反復タイルだったため、画質向上には見えなかった。IVでは画面サイズだけを維持し、主要画面を描き下ろし画像ベースへ変更した。

## 実装方式

- 村: `assets/village-bg-v4.png` をワールド全体の一枚絵として表示し、ゲーム側は当たり判定・NPC・イベントだけを重ねる。
- ダンジョン: `assets/environment-atlas-v4.png` の12種の描き下ろし素材をマップデータに従って配置する。
- 戦闘: `assets/battle-bg-v4.png` を大型背景として使用する。
- 魔物: `assets/monster-atlas-v4.png` の4×3アトラスを各モンスター系統へ割り当てる。
- 主要人物: ソラ、リノ、ガルド、フィオは個別の透過原画を使用する。小型フィールド表示と会話ポートレートの双方で同じデザインを共有する。
- 旧Canvas素材: 読み込みに失敗した場合だけ表示するフォールバックとして残す。

## アートディレクション

青灰色の古塔石、苔、酸化真鍮、深い紺、暖色の灯り、シアンの星術光を共通要素にする。表面には石目、木目、金属傷、植生、水面反射、発光のにじみを持たせる。ピクセル固定拡大は使用しない。

## 生成素材

Built-in ImageGenを使用。村は「古代の天空塔の麓、中央石畳、石造家屋、池、花壇、街灯、シアンの塔紋章」、戦闘背景は「円形観測所、石造アーチ、真鍮天球儀、月光とシアン魔法陣」、人物・魔物・環境はそれぞれ一貫した現代2D JRPG向けの描き下ろし素材として生成した。
