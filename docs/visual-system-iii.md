# Visual System III

## 方針

SFC再現を目標にせず、ゲーム画面上のマス・人物サイズだけを維持する。最終キャンバスは1024×896。1マスは画面上64×64物理ピクセルで表示し、環境素材も64×64で保持するため、拡大による粗さを発生させない。

## 素材解像度

- 環境タイル: 64×64、24種類×11階層配色
- 人物: 128×128原画、4方向、歩行2フレーム（画面上は従来サイズ）
- 通常魔物: 192×192
- ボス: 256×256
- タイトルアート: 1024×896

## 新しい村

旧村の「草原に四角い壁を二つ置く」構造は廃止。屋根、家壁、中央石畳、花壇、街灯、柵、水辺、魔法陣を独立した地形として追加した。宿場町は階層テーマによって同じ構造でも石材・屋根・光源の色が変わる。

## アートディレクション

インクネイビー、孔雀青、古い真鍮、青白い結晶光を共通語彙とする。平坦なベタ面を避け、各素材はグラデーション、目地、反射、細かな摩耗を持つ。人物は曲線・輪郭線・陰影を持つチビキャラ調、魔物は滑らかなイラスト調。最終描画のピクセル固定拡大も廃止し、高品質補間を使う。UIも真鍮の外枠とシアンの内側光で統一する。

## ImageGen基準画

Built-in ImageGenを使用。要旨は「遺跡化した巨大観測所、円形ゲートの先に空中階層と塔、正面寄りのソラ・リノ・ガルド・フィオ、インクネイビー／孔雀青／青灰石／真鍮／深紅、文字・UIなし」。生成結果を `assets/title-keyart-v3.png` として採用した。
