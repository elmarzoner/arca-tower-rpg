# アルカの塔 — ビジュアルデザイン指針

## 全体方針

- 目標は「SFC後期のRPG」。単純な懐古ではなく、限られた色数の中で材質、光、空気を描き分ける。
- 輪郭は濃紺で統一し、完全な黒は穴・最深部・強い影に限定する。
- キャラクターは顔の細部より、髪型、肩、持ち物、裾の形で識別できるシルエットを優先する。
- 環境はベース色、影、ハイライト、局所アクセントの最低4段階で構成する。
- UIは夜空と塔の青を基調に、古い金属を思わせる淡い金の二重枠を使う。

## 主要キャラクター

### ソラ —「光を運ぶのぼりて」

茶色の乱れ髪、青い旅装、短い赤マント。胸の塔の紋章だけをシアンに発光させる。細身だが前傾したシルエットで、怖さを抱えながら進む少年らしさを出す。

### リノ —「暮らしを背負う癒やし手」

橙色の長髪を大きな白リボンでまとめ、ローズ色の旅装に白い肩掛け。薬草ポーチと小さな杖を常に携える。清楚な聖職者ではなく、現場で人を助ける薬師の娘として設計する。

### ガルド —「盾になる古参兵」

暗い短髪、無精ひげ、頬の古傷。くすんだ鋼鎧の左肩だけが赤い。背中の大盾がシルエットの半分を占め、攻める戦士より仲間を守る人物だと一目で分かるようにする。

### フィオ —「真実を読む賢者」

銀白の長髪と深い青緑の非対称ローブ。金の刺繍を縦に走らせ、茶色い古書と青い結晶ペンダントをアクセントにする。魔法使いより研究者に見えることを優先する。

## タイトルアート生成仕様

Built-in ImageGenで制作。プロンプトの要旨: 「後期16-bit機の手打ちピクセルアート。星空と月、雲を貫く古代塔。下三分の一にソラ、リノ、ガルド、フィオを固有装備と読みやすいシルエットで後ろ姿から配置。藍、シアン、石の青灰、琥珀、抑えた赤。文字・ロゴ・UI・透かしなし。」
